# Le Royaume de la Salamandre

Jeu pédagogique pour les 9-11 ans : les débuts de l'imprimerie, la Renaissance et François Ier, sur une carte 3D de l'Europe.

Jouer : https://yoy78.github.io/royaume-salamandre/

- 5 époques, de Gutenberg à Henri II, 39 lieux à explorer
- La France et l'Italie en parallèle, les inspirations grecques et latines
- Plusieurs joueurs, progression enregistrée dans le navigateur, code de sauvegarde

Tout le jeu tient dans `index.html`.
